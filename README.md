# Éxodo Sport · borrador de sitio web

Borrador de tienda online para la boutique de ropa femenina [@moda.exodo.sport](https://www.instagram.com/moda.exodo.sport/).

Abre `index.html` en el navegador para verlo. Es una sola página estática (HTML + CSS + JS), sin dependencias.

Las fotos (siluetas), precios, WhatsApp y el código de descuento son de ejemplo y hay que reemplazarlos por los datos reales.
