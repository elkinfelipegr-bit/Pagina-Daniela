# Exodo Boutique · borrador de sitio web

Borrador de tienda online para [@moda.exodo.sport](https://www.instagram.com/moda.exodo.sport/) (Moda Exodo Boutique, Cumaral, Meta), con un estilo inspirado en tiendas como KOAJ.

Abre `index.html` en el navegador para verlo. Es una sola página estática (HTML + CSS + JS), sin dependencias. Las fotos de `img/` están recortadas de capturas del Instagram de la tienda.

Pendiente de reemplazar: precios (son de referencia), fotos en alta resolución y enlaces de ayuda (cuidados, términos y condiciones).
